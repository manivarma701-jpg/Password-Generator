# 🔐 Password Generator

A clean, fully client-side password generator with strength analysis and clipboard support.

## Features
- Adjustable length (6–32 characters)
- Toggle: Uppercase, Lowercase, Numbers, Symbols
- Real-time strength meter (Very Weak → Very Strong)
- Show / Hide password toggle
- One-click copy to clipboard
- Fisher-Yates shuffle for true randomness

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Structure | HTML5 |
| Styling | CSS3 (Glassmorphism, CSS Variables) |
| Logic | Vanilla JavaScript (ES6+) |

## How to Run
Just open `index.html` in any browser — no dependencies, no build step.
